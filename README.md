# FitTrack — Workout Tracker

A beginner-friendly fitness workout tracker. No accounts, no server — just open `index.html` in your browser.

## Features

- **Rest Timer** — Countdown timer between sets with visual ring indicator
- **Set Tracking** — See which set you're on and how many are left
- **Rep Counter** — Adjust actual reps per set, tracks total reps across your workout
- **Weight Tracking** — Log the weight you're using
- **History** — Remembers your last reps, sets, and weight per exercise (auto-fills next time)
- **HIIT & Strength Exercises** — Pre-loaded categories plus custom exercises
- **Light / Dark Mode** — Toggle in the top bar

## Getting Started

Open `index.html` in any browser. No build step, no dependencies.

## Tech

Plain HTML + CSS + vanilla JavaScript. Data stored in `localStorage`.
